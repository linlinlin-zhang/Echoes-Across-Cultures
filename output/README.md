# Output

## 中文说明

这个目录用于存放渲染、截图、浏览器检查和其他短期工作流产生的临时输出。

### 常见内容

- 浏览器截图
- 本地服务日志
- Playwright 临时输出
- notebook 或 PDF 相关辅助结果

这些文件对调试和核对有帮助，但不属于论文主线证据链。

## English Notes

This directory stores generated temporary outputs from rendering, screenshots, browser checks,
and other short-lived workflow helpers.

### Typical contents

- browser screenshots
- local server logs
- Playwright scratch outputs
- notebook or PDF helper outputs

These files are useful for debugging and verification, but they are not part of the paper mainline evidence chain.
