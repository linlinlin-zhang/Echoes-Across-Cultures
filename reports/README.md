# Reports Index

## 中文说明

这个目录用于存放生成出来的结果、审计报告和分析产物。

### 重要子目录

- `benchmarks/`：主要推荐 benchmark 结果
- `hparam/`：超参数搜索或 reranking sweep 结果
- `pal/`：PAL 对比与回灌训练结果
- `datasets/`：数据集 profile 和审计结果
- `audits/`：工作区或流程审计
- `figures/`：论文或展示用图

### 主线规则

对于当前论文，V4 主线里最优先看的通常是 `benchmarks/`、`hparam/` 和 `pal/`。

## English Notes

This directory stores generated results, audits, and analysis artifacts.

### Important subdirectories

- `benchmarks/`: main recommender benchmark outputs
- `hparam/`: hyperparameter or reranking sweep results
- `pal/`: PAL comparison and retraining outputs
- `datasets/`: dataset profiling and audit outputs
- `audits/`: workspace or process audits
- `figures/`: generated figures for paper or presentation support

### Mainline rule

For the current paper, the highest-priority outputs are in `benchmarks/`, `hparam/`, and `pal/` for the V4 line.
