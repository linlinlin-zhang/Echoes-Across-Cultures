# 曲库风格与元数据质量检查（2026-11-05）

检查对象为当前公开曲库的 30,000 个平台曲目 ID：iTunes 27,449 条、Jamendo 2,551 条。粒度是平台曲目条目，不等同于独立录音。原始 CSV SHA-256 为 `a99b68025c9c123392f7a34bce0183ac5e6bd29c91bc9a491e4e8dba3171ac4e`，本次未改写该文件或模型输入。

## 确认的问题与修复

| 问题 | 证据与影响 | 处理 |
| --- | --- | --- |
| 平台风格名称跨语言混用 | 651 种原始风格写法；截图歌曲 `itunes_691546555` 的原标签为韩语 `록`，其英文市场资料为 `Rock` | 用平台固定风格 ID 对齐，再按七种界面语言显示；中文显示“摇滚” |
| `_en` 字段不保证英语 | 817 条有 `label_en`，其中 709 条仍含中文、日文或韩文；另外 29,183 条为空 | 不再优先信任旧 `_en`；API 提供规范英文名称和七语言名称，保留原始字段用于追溯 |
| 不恰当的直译 | 如 `Dub` →“配音”、`House` →“House 作品”、`Lounge` →“沙发”、`Standards` →“标准” | 音乐语境下校正为“Dub 雷鬼”“浩室”“沙发音乐”“经典标准曲”等；K-Pop 不再被分词替换成“K-流行” |
| 标签种类混在风格列中 | 155 条乐器标签、442 条地域标签、2 条文化标签及 4 条语言标签 | 显式保留“乐器标签／地域标签／文化标签／语言标签”含义，不将国别猜成流派，不将小众标签删除 |
| 广播剧章节混入音乐 | 30 条 `Hörspiele`，为 `Die drei !!!` 的章节记录 | 显示“广播剧”，默认音乐浏览和推荐的 `exclude_low_signal` 过滤排除；原记录和音频仍保留 |
| 时长零值 | 13 条 Jamendo 的 `duration_ms=0`，不能代表实际零秒歌曲 | API 表示为未知时长 `null` / `duration_known=false`，播放仍可使用媒体自身时长；不编造完整歌曲时长 |

651 种原始写法对应 284 个在用的规范词条，全部现有曲目都能解析；7,339 条曲目的展示英文写法得到统一。这是翻译、大小写和别名归一化数量，不能称为 7,339 首歌曲被重新判定了风格。原本不同的 `Afro-Beat` / `Afrobeats` 等细分类保持分开。

## 没有误判为错误的情况

- 曲目 ID、完整行均无重复；曲名、艺人、原风格、文化域必填值没有空值或 `nan/null/unknown` 占位。
- 有 2,012 组相同“艺人＋曲名”，涉及 4,643 条记录。可能包含跨市场条目、重新发行或不同录音；没有凭标题自动去重，需要 ISRC 或音频指纹才能进一步确认。
- 8 条原始发布日期缺失；非空日期格式正常。没有以抓取日期、今天或任意年份代填。
- 人声、语言、乐器/电子属性等可选字段存在来源性缺失，没有按艺人国籍或生成描述推断补齐。

## 实现与可追溯性

- `web/genre-data.json` 与其生成的 `web/genre-data.js` 是前后端共用词典；公开平台分类按 ID 对齐，额外别名及编辑校正在 `configs/genre_aliases.reviewed.json`。词典保留来源 URL、源文件 SHA-256 与人工规则文件 SHA-256。
- `dcas_server/genre_metadata.py` 规范化 API 字段，保留 `label_original/label_en_original/tags_original`，不改曲名、艺人、位置或已有描述。音乐台、图表、曲库列表、收藏和旧浏览器缓存使用同一词典；同一风格的不同语言别名合并统计。
- 搜索索引加入七种语言的规范风格名称；搜索“摇滚”能命中原先写作韩语/日语的 Rock 条目。默认浏览和 GPU 推荐均排除确认的广播剧，直接按 ID 查询与原数据保留。
- `scripts/build_genre_dictionary.py` 可从本地平台分类缓存离线重建，`--fetch` 只在维护时下载公开分类；访客打开网页不请求外部分类服务，也不调用付费翻译/AI。
- `scripts/audit_catalog_quality.py` 保留完整检查与基线，输出汇总、风格别名对照及异常条目表。本机明细保存在 `tmp/catalog-quality-20261105/`；仓库保留[汇总 JSON](catalog-quality-20261105.json)。

平台证据：[韩语分类](https://itunes.apple.com/WebObjects/MZStoreServices.woa/ws/genres?id=34&cc=kr)、[英语分类](https://itunes.apple.com/WebObjects/MZStoreServices.woa/ws/genres?id=34&cc=us)、[截图歌曲英文市场资料](https://itunes.apple.com/lookup?id=691546555&country=US)、[Apple 查询接口说明](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html)。另外下载中文、繁体中文、日语、德语、西语、葡语、法语、意语、瑞典语、荷兰语、土耳其及丹麦市场分类，按同一 ID 对齐。
