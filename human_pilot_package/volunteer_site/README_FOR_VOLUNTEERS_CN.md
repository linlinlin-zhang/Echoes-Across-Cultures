# 跨文化音乐推荐盲听小实验说明

你好，感谢你帮忙做这个小实验。
整个过程大约需要 10-15 分钟。

## 你需要做什么

1. 双击打开 `index.html`。
2. 输入研究者给你的匿名编号，例如 `P01`。
3. 每一题先听“参考音乐”，再听“候选 A”和“候选 B”。
4. 根据直觉回答三个问题。
5. 做完后点击 `导出 CSV`，把下载的 CSV 文件发回给研究者。

## 判断标准

请不要根据国家、语言、乐器或标签直接判断。
更重要的是你的实际听感：

- 哪个更像能接在同一个歌单或相近听歌场景里？
- 哪个更有跨文化新鲜感，但仍然不是乱推？
- 如果系统现在推荐一首让你继续听，你更愿意点哪个？

没有标准答案。
如果真的难以判断，可以选择“差不多 / 不确定”。

## 隐私说明

本实验不需要你的真实姓名。
网页只会导出你的匿名编号和选择结果。
请将导出的 CSV 文件发回给研究者即可。

## 如果网页打不开

请确认这些文件和文件夹还在一起：

- `index.html`
- `app.js`
- `tasks.js`
- `styles.css`
- `audio/`

如果音频无法播放，请换 Chrome、Edge 或 Firefox 打开。
