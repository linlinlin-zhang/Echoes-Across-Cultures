# Workspace Assets

## 中文说明

这个目录用于存放当前仍在使用、但不适合继续散落在仓库根目录的人手导出文件和手工管理材料。

### 当前子目录

- `pal_exports/`：真人 PAL 导出结果与进度快照，用于接入当前 V4 对齐后的 PAL 流程

### 说明

- 这些文件可能会被配置文件或迁移说明文档直接引用
- 它们不是 benchmark 输出本身，而是人工生成的输入材料

## English Notes
