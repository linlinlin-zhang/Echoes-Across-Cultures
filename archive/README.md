# Archive

## 中文说明

这个目录用于存放仍然有保留价值、可供追溯或参考，但已经不属于当前论文系统主线的材料。

### 当前子目录

- `reference_sources/original_idea_notes/`：早期构思文档，例如 `voice_plan*`、`声音*`
- `reference_sources/web_scraps/`：早期探索时留下的临时 HTML 或网页笔记碎片

### 使用原则

- 这里的内容主要用于历史追溯和参考
- 不应把这里当作可复现的 V4 论文主流水线的一部分
- 如果某份材料重新变成现役主线内容，应移回主线目录，并补清楚 README 说明

## English Notes

This directory stores materials that are useful for traceability or background context,
but are no longer part of the active paper-system mainline.

### Current subfolders

- `reference_sources/original_idea_notes/`: early idea documents such as `voice_plan*` and `声音*`
- `reference_sources/web_scraps/`: temporary HTML or note scraps collected during early exploration

### Rule of thumb

- Keep files here for history and reference
- Do not treat this directory as part of the reproducible V4 paper pipeline
- If a file becomes active again, move it back into a mainline directory with a clear README entry
