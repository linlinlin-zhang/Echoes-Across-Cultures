# DCAS Server

## 中文说明

这个目录包含项目的 FastAPI 服务层。

### 作用

- 暴露研究接口和 prototype 接口
- 支持训练、推荐、PAL、本体和原型系统相关流程
- 作为 `dcas/` 核心逻辑与原型系统之间的桥接层

### 主线说明

它对演示、交互和未来数据采集有帮助，但不是论文证据链的主层。

## English Notes

This directory contains the FastAPI service layer for the project.

### Role

- exposes research and prototype endpoints
- supports training, recommendation, PAL, ontology, and prototype flows
- bridges the core `dcas/` logic with the prototype system

### Mainline note

This is useful for demos, interaction, and future data-collection work, but it is not the primary paper evidence layer.
